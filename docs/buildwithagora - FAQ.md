## **Problem Statement Questions**

### **41\. What is the overall theme of the tracks?**

Real-Time Conversational AI Meets Agentic Workflows. The central idea: go beyond conversations and build AI experiences that understand, decide, act and complete real-world journeys.

### **42\. What must every project demonstrate?**

* **Real-time conversational AI:** Agora Conversational AI for natural, low-latency voice interaction (Agora RTC or Chat where relevant)  
* **Natural voice:** Murf AI Falcon TTS for voice output  
* **Agentic workflows:** tool calling, APIs or external integrations that perform actions, not just answer questions  
* **End-to-end user journey:** support before, during and after the main interaction  
* **Working demonstration:** the interaction, the action executed and the resulting outcome

### **43\. What does an end-to-end user journey mean?**

* **Before:** retrieve context such as schedules, preferences or history  
* **During:** understand the request through natural conversation  
* **Action:** complete the task through tools or APIs  
* **After:** confirm, remind, track and follow up

### **44\. What should my demo flow show?**

1. **Initiate:** the user speaks to the agent through Agora Conversational AI and Murf AI Falcon TTS  
2. **Understand / Plan:** the agent interprets the request and works out the next actions  
3. **Execute:** the agent calls tools or APIs to perform the task  
4. **Confirm:** the agent shares the outcome, handles errors and asks approval for critical actions  
5. **Follow up:** the agent updates systems, sends a summary or schedules next steps

### **45\. What is the minimum deliverable for each track?**

| Track | Minimum working deliverable |
| ----- | ----- |
| AI Companions for Everyday Life | At least one complete everyday-life workflow with actions through external integrations |
| Voice AI at Work: Beyond the Call Center | At least one complete workplace workflow using enterprise knowledge and connected systems |
| VibeCart: Shop by Talking | At least one shopping action successfully executed through external APIs |
| AI Agents That Get Things Done | Multi-step reasoning, at least two coordinated tool/API calls and a completed real-world task |
| Voice AI for Bharat: Speak Your Language | Conversation in at least one supported Indian language and an end-to-end service workflow through APIs |

### **50\. Can I add video, a visual interface or physical devices?**
